## 卡在哪 / 怎么解决的
- **问题**：想直接 Read PDF 失败（系统没装 pdftoppm/poppler）
  - 解决：改用 `pip install pypdf` 提取，绕开 PDF 渲染工具
- **概念厘清**：RAG 处理的是「文本」不是格式，PDF 只是容器
  - txt 就是 pypdf 从 PDF 提取的，内容一致 → embedding/检索/答案一致
  - 现实里不用手动转 txt，靠 Document Loader（`PyPDFLoader`）每次运行时自动解析，那是 rag-v2 写 `retriever.py` 时的事
- **关键认知（评测设计第一性原理）**：标准答案 = ground truth = 尺子，必须先忠于原文
  - 故意留差异「测试评测能力」不可行：keyword_recall 的判据来自标准答案关键词，答案漏词 → 判据里没这词 → 模型不提也能满分 → 评测变松失真
