## 这个项目是什么

把暑假做的 mini-RAG（能跑通）升级成 **rag-v2（能评测、能优化）**：
准备评测集 → 手写评测指标 → 根据分数调参数 → 套个界面 → 传上 GitHub。

一句话验收标准：**能回答「召回率多少？怎么测的？调了哪几个参数？结果怎么变？」**

## 为什么做（对标市场）

2026 腾讯云对「大模型应用开发工程师」的第一层能力要求是：**RAG 系统 —— 数据处理 / 检索 / 评测 / 优化**（无训练）。

- 我的 mini-RAG 已经到 **L1 demo**（跑通即止）
- rag-v2 目标是补上 **L3 生产级** 缺的「评测 + 优化」这一侧
- 这是面试官最常追问的点：**评测指标 + 调优过程**，比「我会 RAG」值钱得多
